
# Budget Tracker

## Project Description
Budget Tracker is a simple web application created using HTML and CSS. It helps users record and organize their daily expenses.

## Features
- Expense entry form.
- Expense category dropdown with five options.
- Expense table displaying sample expenses.
- Budgeting tips video.
- Collapsible instructions section.
- Attractive and user-friendly design.

## Technologies Used
- HTML5
- CSS3
- GitHub

## Project Files

### 1. index.html
Contains the structure of the Budget Tracker, including the expense form, expense table, logo, video and instructions.

### 2. style.css
Controls the appearance of the website, including colors, fonts, spacing, table borders, hover effects and advanced CSS selectors.

### 3. README.md
Explains the project, its features and the purpose of each file.

## How to Use
1. Open the Budget Tracker website.
2. Enter an expense name.
3. Enter the expense amount.
4. Select an expense category.
5. Choose the date.
6. Click the Add Expense button.

Note: The form is currently a demonstration. JavaScript functionality will be added in a future lesson.
